# Blog App Homepage

Welcome to the **Blog App** 🚀

---

## Features

- Create and manage blogs
- Like posts
- Add blogs to reading list
- Mark blogs as read/unread
- Secure authentication with NextAuth

---

## Tech Stack

This project uses:

- Next.js (App Router)
- TypeScript
- Drizzle ORM
- PostgreSQL (Neon)
- NextAuth
- Tailwind CSS

---

## About

This is a full-stack blog system built for learning backend + frontend integration in Next.js.

You can:
- read blogs
- track reading progress
- manage users
- interact with server actions

---

## Getting Started

Go to `/blogs` to explore posts or `/users` to view profiles.
